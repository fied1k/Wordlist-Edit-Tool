# Local Release Binary Archive

This folder stores historical standalone binaries for each released version on your local machine.

## Structure
```
releases/
├── v1.0.0/
│   ├── WordLengthFilter.exe   (~12.5 MB Standalone GUI)
│   └── fastfilter.exe         (~95 KB Native C CLI)
└── ...
```

All past versions are also permanently available on the [GitHub Releases Page](https://github.com/fied1k/WordLengthFilter/releases).
