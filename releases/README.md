# Local Release Binary Archive

This folder stores historical standalone binaries for each released version on your local machine.

## Structure
```
releases/
├── v1.0.0/ .. v1.4.0/ (Historical WordLengthFilter.exe & fastfilter.exe)
├── v1.5.0+/
│   ├── Wordlist-Edit-Tool.exe   (~12.5 MB Standalone GUI)
│   └── fastfilter.exe           (~115 KB Native C CLI)
└── ...
```

All past versions are also permanently available on the [GitHub Releases Page](https://github.com/fied1k/Wordlist-Edit-Tool/releases).
