## Purpose
High-performance dictionary and wordlist filtering utility for Windows. Processes multi-gigabyte wordlists (RockYou, custom password dictionaries) in seconds. Ships as a standalone desktop GUI (`Wordlist-Edit-Tool.exe`) and an ultra-fast native C CLI (`fastfilter.exe`). Designed for security engineers and penetration testers.

## Build & Release
```bash
# Install Python dependencies
pip install -r requirements.txt

# Incremental build (native C DLL + CLI + GUI)
.\build.bat

# Run the GUI application
python filter_app.py

# Standalone .exe (PyInstaller)
pyinstaller "Wordlist-Edit-Tool.spec"

# Publish automated release
.\publish_release.bat patch -Notes "Summary of changes"
```

## Token Efficiency & Markdown Caching
- **Never scan full .md files repeatedly**: CHANGELOG.md and README.md consume substantial tokens.
- **Check cache first**: Run `python scripts/md_cache.py check` or check file size/mtime. If unchanged, rely on cached metadata.
- **Incremental changelog**: Read only top lines (`head -n 25`) or use `python scripts/md_cache.py get CHANGELOG.md --latest`.
- **Targeted edits**: Always use line ranges (`StartLine`/`EndLine`) when viewing or editing code.

## Coding Conventions
- **C engine** (`fastfilter.c`): Pure C, no external dependencies beyond stdlib — keep it portable
- **Python GUI** (`filter_app.py`): Tkinter only — no additional GUI framework dependencies
- **ctypes bridge**: Python loads `fastfilter.dll` via ctypes — keep exported function signatures stable
- **Version source of truth**: `version.json` and `VERSION` must remain in sync
- **Naming**: The project is `Wordlist-Edit-Tool` — use this name everywhere

## Key Rules
- `w64devkit/` is a **bundled GCC compiler toolkit** — gitignored and must NEVER be committed
- `fastfilter.dll` is a build artifact — gitignored, regenerated by `build.bat`
- `build/` and `dist/` are PyInstaller outputs — gitignored
- `releases/` contains versioned archives that ARE committed (permanent release history)

## What NOT to Modify
- `Dev/Archive/` — historical snapshots only
- `w64devkit/` — external tool, do not modify
- Exported C function signatures in `fastfilter.c` without updating ctypes bridge in `filter_app.py`
